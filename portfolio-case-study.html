03 / WEB DESIGN · FRONT-END BUILD

A portfolio led
by identity and work.

The portfolio is a responsive profile-first site with a split hero, an original campus-inspired illustration, and a floating section dock. It connects three focused case studies through a hand-coded front end.

01 / THE DIRECTION

Let the person and the work lead.

The homepage takes cues from a profile-first portfolio: one clear name, an honest role description, direct contact links, and visible routes into the work. The layout gives the introduction enough space to feel personal without inventing job history or credentials.

The “Fieldnotes” identity keeps the campus connection through an original illustrated scene, field labels, and a warm neutral canvas. The three project concepts remain the main evidence of design and front-end practice.

02 / VISUAL SYSTEM

Soft neutrals. Strong type. One bright accent.

  • Muted rose-grey gives the profile hero a calm, personal tone.
  • Near-black type and a large two-line name provide a clear first read.
  • Bright blue marks contact actions and the active state in the floating navigation.
  • Original vector artwork brings a campus setting into the hero without borrowing someone else’s portrait.

The system keeps focus indicators, reduced-motion support, and responsive spacing.

03 / REFERENCE STUDY

Use the structure. Make the profile yours.

The reference makes the owner’s name, role, contact links, and section navigation immediately visible. Its oversized profile hero and floating dock became the starting structure for this iteration.

This version uses Marcus’s name, learning goals, portfolio projects, contact details, and an original illustration. The reference owner’s portrait and personal information do not appear here.

Experience history, certificates, testimonials, and location details remain out of the design until Marcus supplies accurate material for them.

04 / FRONT-END NOTES

Build the layout around real reading order.

  • Semantic landmarks and a skip link help keyboard and assistive-technology users move through the page.
  • CSS Grid and flexible sizing adapt the hero, project list, and footer to smaller screens.
  • The floating dock links directly to page sections and indicates the current section as the visitor scrolls.
  • Reduced-motion support and visible focus states keep interaction details predictable.
  • Project demos use native controls, labels, and client-side interactions.

The pages are static and require no build step. The personal details come from Marcus; project scenarios and sample data are clearly labeled concepts.

05 / NEXT ITERATION

Keep the work personal and specific.

The portfolio now includes Marcus’s preferred name, contact email, and GitHub profile. As the projects develop, add only the feedback, decisions, and outcomes that reflect work actually completed.

This page describes the design intent and implementation choices; it does not claim user testing or measured results.
