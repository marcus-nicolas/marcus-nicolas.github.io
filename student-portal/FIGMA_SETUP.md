# Open the portal wireframes in Figma

The SVG is a starting artifact for the Student Portal design exercise. It contains the desktop and mobile wireframes side by side.

1. Open your Figma design file.
2. Import or drag `figma-wireframes.svg` onto the canvas.
3. Keep one copy as a reference. Use the other copy to practice rebuilding the layout with native Figma frames, rectangles, and text layers.
4. Name the frames **Desktop / 1440 × 1000** and **Mobile / 390 × 844**.
5. Compare the mobile information order with the desktop. Keep the next class first, then deadlines, the important notice, and the schedule.
6. Add visual styling only after the hierarchy feels clear.

The file uses fictional sample content and states the unvalidated problem hypothesis. Replace or adapt it only if you can explain the design choices honestly.
