# Fieldnotes — UI/UX & front-end portfolio

An editorial portfolio project built around the idea of field notes: observe a small point of friction, frame a user goal, then design and build a useful interface. The home page uses a profile-first split hero, original campus-inspired illustration, oversized typography, compact contact links, and a floating section dock. Three focused project concepts connect UI/UX practice with front-end implementation.

## Contents

- `index.html` — portfolio landing page and selected work.
- `portfolio-case-study.html` — visual and front-end case study for this site.
- `styles.css` — portfolio design system and responsive layout.
- `script.js` — accessible mobile navigation and current year.
- `student-portal/` — dashboard case study, responsive prototype, brief, Figma-ready wireframes, and setup notes.
- `appointment-booking/` — booking-flow case study and interactive prototype.
- `projects.css` — shared case-study and prototype styles.
- `LEARNING_GUIDE.md` — a guided code walkthrough and practice tasks.

## Open locally

Open `index.html` in a browser. The site uses no build step or third-party JavaScript libraries. Google Fonts are requested when the browser is online; system fallbacks are defined for offline viewing.

## Hosting

Live site: `https://marcus-nicolas.github.io/`. This is a static site with no build step and deploys to GitHub Pages from the `main` branch with GitHub Actions. `.nojekyll` is included.

## Project integrity

The student portal and appointment booking app are self-initiated concepts with fictional organizations and sample data. Their problem statements are hypotheses. No user research, usability test results, real appointments, or measured outcome improvements are claimed.
